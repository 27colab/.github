# Security policy

These are small open-source reference libraries (version 0.x). If you find a security problem, please report it privately.

**How to report:** open the repository's **Security** tab and choose **Report a vulnerability** (GitHub private vulnerability reporting). Please do not open a public issue for security problems.

Include what you found, how to reproduce it, and which version or commit. I will acknowledge a report within a few days and tell you what I plan to do. These packages never ship API keys, tokens or real customer data; if you spot a secret or personal data in any repository, report it the same way.
